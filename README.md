# 🚌 Expresso Viajante

Projeto web desenvolvido durante meu processo de aprendizado em desenvolvimento web, com foco na criação de uma plataforma de turismo e na aplicação de boas práticas de HTML semântico e acessibilidade.

O Expresso Viajante apresenta destinos turísticos brasileiros e permite navegar por informações sobre diferentes localidades, além de contar com páginas de cadastro, login e carrinho.

## Objetivo do projeto

O projeto foi criado para colocar em prática conhecimentos adquiridos durante meus estudos de desenvolvimento web, principalmente HTML e CSS, utilizando como tema uma plataforma de turismo.

Além da construção das páginas e da organização visual, o projeto também foi utilizado para aplicar conceitos de acessibilidade na web, buscando tornar a navegação e os conteúdos mais compreensíveis para diferentes usuários.

## Acessibilidade

Durante o desenvolvimento, foram aplicadas práticas de acessibilidade e HTML semântico, incluindo:

- Textos alternativos (`alt`) em imagens;
- Associação de campos de formulário com `label`;
- Uso de `fieldset` para agrupamento de informações;
- Uso de atributos `aria-label` e `aria-current`;
- Definição do idioma da página com `lang="pt-BR"`;
- Uso de elementos semânticos do HTML;
- Descrições e identificação de conteúdos visuais.

## Funcionalidades

- Página inicial com apresentação de destinos turísticos;
- Páginas individuais com informações sobre diferentes destinos;
- Página de cadastro de usuário;
- Página de login;
- Página de carrinho;
- Navegação entre as diferentes áreas do site;
- Estruturação de conteúdo com foco em semântica e acessibilidade.

## Tecnologias utilizadas

- HTML5
- CSS3

## Estrutura do projeto

O projeto está organizado em páginas HTML separadas para as principais funcionalidades e utiliza arquivos CSS para a estilização das interfaces.

Principais elementos da estrutura:

- `index.html` — página inicial;
- páginas individuais para destinos turísticos;
- páginas de login, cadastro e carrinho;
- pasta `assets/css` — arquivos de estilo;
- pasta `assets/img` — imagens utilizadas no projeto.

## Aprendizados

Durante o desenvolvimento e aprimoramento deste projeto, pratiquei principalmente:

- Estruturação de páginas com HTML;
- Organização e estilização de interfaces com CSS;
- Criação e estilização de formulários;
- Navegação entre diferentes páginas;
- Uso de elementos semânticos;
- Aplicação de conceitos básicos de acessibilidade;
- Organização de layouts utilizando Flexbox;
- Aplicação de responsividade básica com Media Queries;
- Organização de arquivos em um projeto web.

## Status do projeto

O Expresso Viajante foi desenvolvido como um projeto de aprendizado e permanece aberto a melhorias e novas implementações.
